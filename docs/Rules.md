# Pixel Wizard Rules and Compliance

Source: `Pixel_Wizard+rules.pdf`, supplied with this project.

## Official requirements

- Team size must be 2–3 participants.
- The team must select and work on only one problem statement.
- Any frontend technology, programming language, framework, UI library, or development tool may be used.
- The chosen technologies must work together and the final website must be usable and responsive.
- Development must take place during the official competition period.
- The repository name must match the team's official name.
- The submitted work must be original.
- The repository/demo link must be submitted before the deadline.
- The GitHub repository must be public and accessible to judges.
- Organizer instructions must be followed.
- Judges' decisions are final.

## Selected problem statement

**Problem Statement 3: Hostel Management System**

HostelHub will present student information, room allocation, complaint tracking, mess menus, and hostel announcements. Mock data and browser storage are used; no backend or database is required.

## Prohibited or unsafe practices

The PDF states that the following are not permitted during the competition:

- LLMs
- AI coding assistants
- Agentic models
- AI-generated code or content
- Previously completed projects
- Copied websites
- Prebuilt templates

The wording is broad. The team should ask organizers how they interpret pre-event planning documents, generated assets, external libraries, and any other assistance before the competition starts. During the official period, the safest policy is to create code, copy, visual assets, and design decisions without prohibited assistance.

## HostelHub compliance decisions

- Frontend-only implementation
- Next.js + TypeScript
- Mock data and browser `localStorage`
- No API, database, authentication provider, or server persistence
- Clearly labelled Student/Admin login paths
- Original visual system: Bold Campus Editorial
- Original product copy and seeded data
- No copied template or cloned commercial website
